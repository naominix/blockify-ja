# ブロッキファイ（Blockify 日本語版）

3Dモデル（STL / OBJ / GLB / glTF / 3MF）をボクセル化して、Minecraftで建築するための
層ごとの設計図（ブループリント）に変換するWebアプリです。
[Blockify](https://blockify-358752380494.us-west1.run.app/) と同じ機能を、日本語で再実装しました。

**ファイルは外部に送信されません。** 変換はすべてブラウザの中で完結します。

## 機能（元サイトとの対応）

| 元サイト | 本アプリ |
|---|---|
| SELECT 3D MODEL (STL/OBJ/GLB)、DROP FILE OR CLICK | 3Dモデルを選択、ファイルをドロップ／クリック（glTF・3MFも追加対応） |
| GRID SIZE スライダー 16〜128（刻み8、初期値32） | グリッドサイズ（同仕様） |
| SOLID / HOLLOW トグル | 中身あり／中空トグル |
| （なし） | モデルの上方向（縦軸）切替：自動（STL／OBJ／3MFはZが上、GLBはYが上）／Zが上／Yが上 |
| VOXELIZE | ボクセル化する |
| 3D PREVIEW（ドラッグ回転、ズーム 0.5〜3、SHOWING FULL / LAYER VIEW） | 3Dプレビュー（同仕様） |
| BLUEPRINT（レイヤー送り ◀▶、現在層／全層数） | 設計図（同仕様、ホバーでブロック名と座標を表示） |
| INVENTORY + Change Material（ブロック123種、検索付き） | 必要なブロック + 素材を変更（123種すべてに日本語名付き、検索は日本語／英語／ID対応） |
| Get Export Code → Python Script / MC Commands、COPY TO CLIPBOARD | 書き出しコードを取得（同仕様。**元サイトのタブ切替バグは修正済み**で、タブで内容が切り替わります） |
| Download PDF（表紙：総レイヤー数と必要素材） | PDFをダウンロード（表紙＋**全レイヤーの設計図ページ付き**に拡張） |
| （なし） | JSONをダウンロード（ボクセル座標の機械可読データ）を追加 |

## 技術構成（GitHub Pagesで公開できる理由）

- **完全な静的サイト**：サーバー処理なし。`index.html` を置くだけで GitHub Pages で公開できます。
- **WebAssembly**：中身あり（SOLID）判定の外側フラッドフィルを自作WASMモジュール
  （ソースは `wasm/floodfill.wat`、539バイト）で実行します。WASMバイナリは
  Base64で `voxel-worker.js` に埋め込んであるため、追加ファイルなしで動作します
  （`wasm/floodfill.wasm` は同じモジュールの単体ファイル版）。
  WASMが使えない環境ではJavaScript実装に自動で切り替わります。
- **Web Worker**：ボクセル化（三角形とボクセルの交差判定）を `voxel-worker.js` で
  バックグラウンド実行し、画面を固まらせません。
- **WebGL**：3Dプレビューは Three.js（CDN読み込み、InstancedMeshで高速描画）。
- PDF生成は jsPDF（CDN読み込み）。

## GitHub Pagesへの公開手順

1. GitHubで空のPublicリポジトリを作成する（例：`blockify-ja`）
2. このフォルダの中身をそのままリポジトリのルートにpushする
   （WASMは埋め込み済みなので、`wasm/` フォルダはソース参考用です）
3. リポジトリの Settings → Pages で Source を「Deploy from a branch」、
   Branch を「main」／「/ (root)」にして保存する
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

## ローカルで動かす

ESモジュールとWASMを使うため、`file://` では動きません。簡易サーバーで開いてください。

```bash
python3 -m http.server 8000
# http://localhost:8000/ をブラウザで開く
```

## 検証済みの動作

立方体STL（12三角形）でのボクセル化結果：

- グリッド16・中身あり： 4,096個（16³と一致）
- グリッド16・中空： 1,352個（16³ − 14³ と一致）
- グリッド32・中身あり： 32,768個（32³と一致）
- グリッド32・中空： 5,768個（32³ − 30³ と一致）
- WASMフラッドフィル単体テスト：殻状立方体で内側1セルを正しく判定

## 制限

- 閉じていない（穴の開いた）メッシュでは「中身あり」の内側判定が正しくならないことがあります。
- 大きなグリッド（128）と面数の多いモデルでは、変換に時間がかかります。
- テクスチャの色に応じたブロックの自動割当は元サイトにも無く、本アプリでも単一素材方式です
  （素材は「素材を変更」からいつでも切り替えられます）。
